# Autodidact capture policy. The server serves this file to every browser extension at GET /policy
# (they refresh it hourly) and also enforces it on /ingest, so one edit here applies everywhere.
# On the Pi the live copy is /srv/autodidact/data/policy.txt, seeded from this file on first start;
# edit that one. Changes take effect on the next request, no restart needed.
#
# One rule per line; blank lines and lines starting with # are ignored.
#   example.com           host glob: * matches anything (*.bank*, *chase.com)
#   *youtube.com/shorts/  host glob + path prefix (path and query string, from the first /)
#   https://x.com/a/b     full URL prefix
#   !skip-front-pages     directive: never capture a site's front page (path "/" or empty)
#   !allow <rule>         directive: never block what <rule> matches (wins over everything above)
#   !allow-platform a b   directive: keep front pages the extension identifies as a blog on platform a or b
#                         (wordpress, substack, ghost, blogger); lifts only the front-page skip
#
# The extension's own Settings blocklist still applies on top of this (passwords, banks, LAN ranges).
# These rules only cover browser captures; FreshRSS items and share-sheet links are not filtered.

# Front pages are link lists that change all the time; each change was being stored as a new page.
!skip-front-pages
# ...except blog platforms, where the front page is the latest posts (Paul, 2026-10-20). Blogs on
# their own domains are not covered by these. "!allow <rule>" overrides every block rule.
!allow *.substack.com
!allow *.wordpress.com
# Blogs on their own domains: the extension (0.1.6+) recognises the platform from the page markup and
# whether the front page shows a few full posts (a blog) or many short teasers (a news site).
!allow-platform wordpress substack ghost
